# Mangyan Heritage React

A React + Vite educational digital heritage website about the distinct Mangyan communities of Mindoro.

## Run locally

```bash
npm install
npm run dev
```

## Build for deployment

```bash
npm run build
npm run preview
```

**Important:** Do not upload or commit `node_modules`. The project is intentionally packaged without it so Vite/Rollup installs the correct dependencies for the computer or deployment server.
